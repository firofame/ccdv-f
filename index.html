💾 Prompt Caching

  • TTL: 5-minute sliding window (refreshed on cache hits).
  • Min Tokens: Minimum token threshold required for prompt prefix caching.
  • Cost Savings: Up to 90% discount on cache read tokens vs base inputs.
  • Breakpoint: Add "cache_control": {"type": "ephemeral"} to tool definitions or system prompts.

🤖 Agent SDK & Harness

  • Code Harness: Outer wrapper executing the agentic loop and state machine.
  • PreToolUse Hook: Intercepts tool calls before execution (validation, policy check, authorization).
  • PostToolUse Hook: Sanitizes output, strips sensitive data, and handles errors.
  • Agentic Loop: Model predicts tool call → Harness executes → Result appended → Repeat until stop.

🔌 Model Context Protocol (MCP)

  • Resources: Static or contextual data read by the LLM (like files or database schemas).
  • Tools: Executable functions that cause side effects or query live APIs.
  • Prompts: Pre-packaged prompt templates exposed by the server.
  • Transport: Stdio (standard in/out) or Streamable HTTP.

⌨️ Claude Code CLI Commands

  • /compact — Summarize conversation context to reclaim token window.
  • /clear — Reset session context and scratchpad.
  • /resume & /fork — Re-open or branch an earlier working session.
  • /context — Inspect current token breakdown and loaded memory.
  • /rewind — Undo previous agent state changes or file edits.
  • /fast & /effort — Adjust reasoning depth and latency.

🛡️ Guardrails & Security

  • Sandboxing: Run untrusted generated code in isolated containers or jails.
  • Permission Modes: Plan mode (read-only draft) vs Accept mode (auto-execute).
  • Data Leakage: Redact PII in pre-hooks before tokens reach the API.
  • Injection Defense: Enforce strict delimiter boundaries and XML schema wrapping.

🎯 Model Selection Tradeoffs

  • Agentic Loop Models: Selecting models optimized for reliable tool execution and agentic workflows.
  • Adaptive Thinking: Dynamic token allocation matching thinking depth to task complexity.
  • Extended Thinking: Configurable reasoning budget for deep multi-step architecture and debugging.
